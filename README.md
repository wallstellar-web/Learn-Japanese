# Japanese Learner (web app)

Search Japanese words, see romaji and English-style pronunciation, hear them spoken.
Installable on iPhone/Android/desktop as a Home Screen web app (PWA).

- Offline: word bank, kana lookup, pronunciation, audio
- Online (optional): kanji and English lookup via your own Anthropic API key (Settings in the app)
